INTRODUCTION

A Simple Portfolio Project

In this project, we explored how to create a simple yet meaningful portfolio website. This experience helped us understand not only the technical aspects of web development but also the importance of creativity and problem-solving.

Written by Zhafira Nadya Syfa

Recount Text

Orientation

As students of Software Engineering, we learned many things about technology, especially web development. In this project, we created a simple personal portfolio website using HTML, CSS, and JavaScript. We also used frameworks such as Tailwind CSS and Bootstrap to make the design more efficient and responsive. In addition, we used tools like Visual Studio Code to write and organize our code, and AOS (Animate On Scroll) to add animations. These tools helped us work more effectively and made the website look more modern and interactive.

Events

First, we started by planning the structure of the website. We discussed what sections should be included, such as the home page, about section, skills, and portfolio. After that, we created the basic layout using HTML. Next, we focused on styling the website. We used Tailwind CSS to quickly design the layout and applied Bootstrap for some components. At this stage, we learned how to combine different frameworks and adjust them to match our design.

During the development process, we faced several challenges. Sometimes the layout did not look as expected, and some elements were not responsive. We also experienced difficulties with JavaScript, especially when handling interactions and animations. However, we did not give up. We tried to fix the problems by searching for solutions on the internet, reading documentation, and asking for help when needed.

Slowly, we began to understand our mistakes and improved our coding skills. After that, we added animations using AOS to make the website more engaging. At first, the animations did not work properly, but after several attempts, we successfully implemented them. This made the website feel more alive and professional.

Finally, we tested the website on different screen sizes to make sure it worked well on both desktop and mobile devices. We made several adjustments until we were satisfied with the result.

Re-orientation

Through this experience, we learned that building a website required patience, creativity, and consistency. We also realized that using frameworks could speed up the development process, but understanding the basic concepts was still very important.

We felt proud of what we achieved because we were able to complete the project despite the challenges. This project also increased our confidence in web development and motivated us to continue learning and improving our skills in the future.
